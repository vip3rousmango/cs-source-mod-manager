# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner through the GitHub security advisory flow for `vip3rousmango/cs-source-mod-manager`.

Include:

- affected version or commit
- operating system
- reproduction steps or a minimal fixture
- impact and any known workaround

The project is especially interested in reports involving archive traversal, symlink handling, unsafe Electron IPC exposure, unintended writes outside the manager-owned directory, and release artifact tampering.

## Supported versions

Only the latest published release and the default branch receive security fixes while the project is pre-1.0.
